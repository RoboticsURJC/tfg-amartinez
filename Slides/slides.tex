\subsection{Descripción del problema}
\begin{frame}{Descripción del problema}

\begin{figure}
\centering
\includegraphics[width=0.8\textwidth]{figs/esquema_problema.png}
\end{figure}

\note[item]{
El envejecimiento de la población y el aumento de enfermedades crónicas hacen que muchas personas deban gestionar tratamientos con múltiples medicamentos y diferentes horarios de administración. Esta situación incrementa el riesgo de olvidos y errores, poniendo de manifiesto la necesidad de soluciones inteligentes que faciliten la dispensación y el seguimiento de la medicación en el entorno doméstico.
}
\end{frame}

\subsection{Objetivos}
\begin{frame}
\frametitle{Objetivos}

\begin{block}{Objetivos}
\begin{itemize}
\item Diseñar la \alert{arquitectura general} del sistema.
\item Desarrollar el \alert{diseño mecánico} del pastillero.
\item Integrar el \alert{microcontrolador} y la lógica de control.
\item Implementar una \alert{interfaz táctil} intuitiva.
\item Incorporar un \alert{sensor biomédico}.
\item Desarrollar una \alert{aplicación Android}.
\item Implementar la comunicación \alert{WiFi}.
\item Realizar la \alert{validación experimental}.
\end{itemize}
\end{block}

\note[item]{
El objetivo principal del trabajo ha sido desarrollar un sistema inteligente para el entorno doméstico. Para alcanzarlo se definieron varios objetivos específicos relacionados con el desarrollo del dispositivo, la aplicación móvil, la comunicación entre ambos y la validación experimental.
}

\end{frame}

\subsection{Requisitos}
\begin{frame}
\frametitle{Requisitos}

\begin{block}{Requisitos}
\begin{itemize}
\item Uso de \alert{ESP32-2432S028}.
\item Desarrollo en \alert{C++} y \alert{Kotlin}.
\item Comunicación mediante \alert{WiFi}.
\item Funcionamiento en \alert{tiempo real}.
\item Fabricación mediante \alert{impresión 3D (PLA)}.
\item Coste inferior a \alert{50\,€}.
\item \alert{Almacenamiento} de medicación y medidas.
\item Avisos \alert{visuales y acústicos}.
\end{itemize}
\end{block}

\note[item]{
Además de los objetivos, el sistema debía cumplir una serie de requisitos de diseño y técnicos. Entre ellos destacan el bajo coste, el funcionamiento autónomo, la comunicación WiFi, una arquitectura modular y el uso de un ESP32 como unidad de control.
}

\end{frame}

\begin{frame}
\frametitle{Arquitectura general del sistema}

\begin{center}
    \includegraphics[width=\textwidth]{figs/arquitectura_sistema.jpg}
\end{center}

\note[item]{
Una vez definidas las herramientas de desarrollo, el siguiente paso fue diseñar la arquitectura del sistema.

En el centro se encuentra el ESP32, que actúa como unidad de control. Este microcontrolador gestiona la interfaz táctil, la comunicación WiFi con la aplicación Android, el accionamiento del servomotor para la dispensación y la adquisición de datos del sensor biomédico MAX30102 mediante I2C.

La aplicación móvil permite configurar el dispositivo y consultar la información registrada, mientras que el usuario también puede interactuar directamente desde la pantalla integrada.

Esta arquitectura modular facilita la integración de todos los elementos hardware y software del sistema.

\vspace{0.4cm}

\begin{block}{Resultado}
Se realizaron diversas iteraciones del mecanismo de dispensación hasta conseguir un sistema capaz de posicionar correctamente el compartimento y dispensar una única dosis de forma repetible.
\end{block}

\note[item]{
El mecanismo no funcionó correctamente desde el primer diseño. Fue necesario modificar el impulsor en varias ocasiones, ajustar su geometría y la posición del trinquete hasta obtener un funcionamiento fiable. Finalmente, el mecanismo fue capaz de posicionar correctamente el carrusel y dispensar una única pastilla en cada activación del servomotor.
}

\end{frame}

\subsection{Integración MAX30102}

\begin{frame}
\frametitle{Integración del sensor MAX30102}

\begin{center}
    \includegraphics[width=0.7\textwidth]{figs/esquema.jpg}
\end{center}

\note[item]{
El pulsómetro se implementó mediante el sensor biomédico MAX30102, conectado al ESP32 utilizando el protocolo I2C.

La alimentación se realiza a 3.3 voltios y únicamente son necesarias dos líneas de comunicación, SDA y SCL, lo que simplifica considerablemente la integración hardware del sistema.

Una vez integrado, el sensor proporciona la señal fotopletismográfica utilizada para estimar la frecuencia cardíaca.
}
\end{frame}

\begin{frame}
\frametitle{Procesamiento de la señal PPG}

\begin{center}
    \includegraphics[width=0.95\textwidth]{figs/sensor_esquema.jpg}
    \caption{Elaboración propia mediante IA}
\end{center}

\note[item]{
El sensor ilumina el dedo mediante LEDs rojo e infrarrojo y el fotodiodo recoge la luz reflejada por el flujo sanguíneo.

A partir de esta señal PPG se detectan los picos correspondientes a cada latido, se calcula el intervalo entre pulsos y se obtiene la frecuencia cardíaca instantánea.

Finalmente, el firmware aplica un promedio y un filtro exponencial para reducir el ruido y mejorar la estabilidad de las medidas antes de mostrarlas al usuario.
}
\end{frame}

\begin{frame}
\frametitle{Resultados experimentales del sensor}

\begin{center}
    \includegraphics[width=0.95\textwidth]{figs/experimento_sensor.png}
\end{center}

\note[item]{
Se realizaron pruebas en cuatro posiciones distintas del dedo para analizar el tiempo necesario hasta obtener una medida estable.

Cada configuración se repitió dos veces y se calcularon los valores medios.

Los resultados muestran que la orientación del dedo afecta al tiempo de estabilización, obteniéndose el mejor comportamiento con la mano derecha en posición vertical.
}

\end{frame}

\begin{frame}
\frametitle{Comparación con pulsioxímetro comercial}

\begin{center}
    \includegraphics[width=0.85\textwidth]{figs/experimento_comercial.png}
\end{center}

\note[item]{
Como validación final, las medidas del sistema desarrollado se compararon con un pulsioxímetro comercial.

La diferencia observada entre ambos dispositivos fue reducida, lo que confirma que el algoritmo implementado proporciona una estimación fiable de la frecuencia cardíaca para el objetivo del proyecto.
}

\end{frame}

\begin{center}

\note[item]{
